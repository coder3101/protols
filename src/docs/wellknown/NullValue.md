`google.protobuf.NullValue`

---

**Well-Known Type**

`NullValue` is a singleton enumeration to represent the null value for the `Value` type union.

The JSON representation for `NullValue` is JSON `null`.

**Values:**

- `NULL_VALUE`: Null value.

```protobuf
enum NullValue {
  NULL_VALUE = 0;
}
```
